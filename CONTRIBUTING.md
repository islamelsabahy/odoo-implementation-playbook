# Contributing

Contributions are welcome.

## Contribution Types

- New Odoo module test cases
- Improved project governance templates
- Data migration checklists
- UAT scenarios
- Go-live controls
- ERP implementation lessons learned
- Industry-specific examples

## Rules

1. Keep templates vendor-neutral where possible.
2. Clearly identify Odoo-specific behavior when relevant.
3. Do not include customer-confidential data.
4. Use dummy data in examples.
5. Keep business requirements separate from solution decisions.
6. Document assumptions.
