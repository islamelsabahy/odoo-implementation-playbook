# Go-Live Readiness Checklist

## Scope & Solution
- [ ] Scope baseline approved
- [ ] Critical requirements delivered
- [ ] Configuration documented
- [ ] Approved customizations deployed
- [ ] Integrations validated

## Data
- [ ] Master data approved
- [ ] Final migration completed
- [ ] Opening balances reconciled
- [ ] Customer/vendor balances reconciled
- [ ] Data sign-off received

## Testing
- [ ] UAT completed
- [ ] Critical defects = 0
- [ ] Major defects have approved disposition
- [ ] Regression testing completed
- [ ] Key reports validated

## Users
- [ ] Production users created
- [ ] Access rights validated
- [ ] Key users trained
- [ ] End users trained
- [ ] Support contacts communicated

## Operations
- [ ] Cutover plan approved
- [ ] Backup / recovery confirmed
- [ ] Rollback criteria approved
- [ ] Hypercare team confirmed
- [ ] Escalation path communicated

## Governance
- [ ] Business sponsor approval
- [ ] Finance approval where relevant
- [ ] IT approval
- [ ] Implementation partner approval
- [ ] Final Go / No-Go decision recorded
